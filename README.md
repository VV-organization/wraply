# Wraply
Магазин скинов CS2, Rust и Team Fortress 2 в тёмной теме. Курс **1 Wraps = 1,8 ₽**.

## Локальный запуск
Требуется Node.js 24. Установите зависимости командой `npm ci`, затем выполните `npm run dev` и откройте [Wraply](http://127.0.0.1:5378). Для проверки доступны `npm test`, `npm run lint`, `npm run typecheck` и `npm run build`.

Снимок каталога загружается по выбранной игре. Для витрины используются локальные изображения, для полного каталога — изображения из источника с состоянием недоступности. Корзина, избранное и профиль сохраняются в браузере. Платежи, Steam OpenID и выдача предметов пока не подключены.

Этапы работы описаны в [промтах](project-prompts.md), источники визуальных решений и тёмная палитра — в [дизайн-системе](DESIGN.md).

## Публикация
Публичная версия: [VV-organization.github.io/wraply](https://vv-organization.github.io/wraply/).

Push в `main` запускает `.github/workflows/pages.yml`: линтер, тесты, статическую сборку и публикацию GitHub Pages. Локальная проверка той же сборки: `npm run build:pages`; результат находится в `out-pages`, базовый путь `/wraply`. Секреты для публикации не требуются: workflow использует стандартный `GITHUB_TOKEN` и OIDC GitHub Pages.
