# Проверка стикеров нижнего каталога

## Референс и реализация
- В браузере изучен нижний CTA https://www.extrafazant.nl/: движение указателя, форма/размер и исчезновение наклеек.
- Параметры сверены с ранее сохранённым публичным скриптом референса `/tmp/wraply-reference-motion.js`, функция image trail. Вместо GSAP используются семплированные кривые Web Animations API.
- Девять локальных вариантов: Sport Gloves Vice, Shadow Daggers Ultraviolet, Doodle Metal Facemask, Rainbow Pony Hoodie, Starlight Sorcerer, That '70s Chapeau; оригинальные SVG-надписи RUSH B, RAID TIME, MEDIC!. Шрифт Inter Black из существующего OFL-шрифта преобразован в кривые.

## Проверки
- Настольный экран 1440×900: повторные проходы указателем, смена игровых вариантов, отсутствие стикеров после завершения, отсутствие горизонтального переполнения.
- CTA остаётся поверх изображений; Enter открывает `/catalog`.
- Общий футер на главной и странице соглашения; мобильный экран 390×844: заголовок и кнопка помещаются, переход в каталог работает.
- Код отключения для reduced motion и coarse pointer проверен; системные настройки устройства для этого не менялись.
- Независимый агент проверил alpha/идентичность шести картинок и код очистки/доступности. Дефектов не отметил. Это техническая проверка, не пользовательское исследование.
- Typecheck, lint, 53 теста и diff-check прошли. Сборка Pages прошла: 106 статических маршрутов.

Изменения локальные; не опубликованы.
